# Проверка графового расширения контекста

Дата: 2026-10-20.

## Объём реализации

Модуль:
`src/philosophy_influence_explorer/retrieval/graph_context_retriever.py`.

Тесты:
`tests/test_graph_context_retriever.py`.

Реализован отдельный read-only retriever для маршрута:

`seed Passage -> DISCUSSES -> Concept <- DISCUSSES <- related Passage`.

Модуль принимает идентификаторы исходных passages.
Он не вычисляет embeddings, не генерирует ответ
и не изменяет существующий passage-search API.

## Правила отбора

- Все узлы и оба отношения ограничены dataset `curated_corpus_v1`.
- Обходятся только отношения со статусами `reviewed` и `curated`.
- У обоих отношений требуется наличие стабильного ID.
- Исходный passage не возвращается как собственное дополнение.
- Фильтры языка и происхождения применяются к дополнительным passages.
- Фильтр семейства применяется к связывающему концепту.
- Статус дополнительного passage возвращается без изменения;
  разрешённый статус ребра не означает утверждения текста.
- Лимит задаёт общее число путей по всем переданным seeds.
- Разные пути к одному passage сохраняются.
- Сортировка задаётся идентификаторами, а не оценкой релевантности.
- Векторная оценка дополнительным passages не присваивается.

## Проверка на Aura

Запуск выполнен пользователем локально через
`GraphContextRetriever.expand()` с подключением к Aura.

Исходный passage:
`passage:hegel:wl:being:de`.

Общий концепт:
`concept:becoming`.

Дополнительные passages:

- `passage:hegel:wl:being:en`.
- `passage:hegel:wl:being:ru`.

| Проверка | Параметры                            | Результат                                     |
| -------- | ------------------------------------ | --------------------------------------------- |
| G1       | Без фильтров, limit=20               | 2 пути: EN и RU                               |
| G2       | language=ru                          | 1 путь: RU                                    |
| G3       | is_verbatim=true, is_editorial=false | 0 путей                                       |
| G4       | limit=1                              | 1 путь: EN, совпадает с первым результатом G1 |

В G1 проверены направления и идентификаторы рёбер,
статусы отношений, тип и признаки происхождения текста,
наличие source_id, work_id, citation_label и текста.

Статус исходного отношения: `reviewed`.
Статус дополнительных отношений: `curated`.
Тип дополнительных passages: `editorial_summary`.
Статус дополнительных passages: `curated`.

Итог запуска: `PASS: G1-G4 completed successfully.`

Временные переменные подключения после проверки удалены.
Пароли в протокол не включены.
Запись данных, seed и переиндексация не выполнялись.

## Границы подтверждения

- Проверен один исходный passage и общий концепт becoming.
- Исключение candidate/rejected-рёбер задано запросом
  и проверено структурными unit-тестами, но отдельный
  отрицательный сценарий на Aura пока не выполнен.
- Несколько seeds, фильтр семейства концептов и несколько
  разных путей к одному passage на Aura отдельно не проверены.
- Маршрут означает общую концептуальную аннотацию,
  а не историческое влияние или независимое подтверждение.
- Редакционные изложения не считаются переводами.
- Полнота всех графовых связей и производительность
  на большом корпусе не проверялись.
