# Первичный корпус: локальная партия 2026-11-22

## Назначение

Переход от исследовательских пересказов к полным текстам произведений.
Этот патч добавляет каталог и автономные инструменты; данные приложения
в data/curated и исходные схемы не изменяются.

## Два отдельных архива

1. primary-corpus-local-2026-11-22.zip — ПОЛНЫЕ ТЕКСТЫ. Распаковать вне Git,
   например в C:\philosophy-corpus. Не коммитить.
2. primary-corpus-project-2026-11-22.zip — каталог, отчёт и инструменты.
   Распаковать в корень philosophy-influence-explorer после проверки конфликтов имён.

## Проверка (PowerShell, из корня проекта)

```powershell
uv run --no-sync python scripts/corpus/inspect_local_corpus.py --root C:\philosophy-corpus
```

Ожидается status=ok, sources=3, pdf_leaves=1552, works=24.
Скрипт использует только стандартную библиотеку Python, не читает .env,
не обращается к базе и провайдерам.

## Буквальный поиск по самим произведениям

```powershell
uv run --no-sync python scripts/corpus/search_local_corpus.py --root C:\philosophy-corpus --query "непостиж" --author cusanus --limit 5
uv run --no-sync python scripts/corpus/search_local_corpus.py --root C:\philosophy-corpus --query "непостиж" --author frank --limit 5
```

Это поиск подстроки с адресом в источнике, не семантический retrieval, не
полное тематическое исследование и не генерация ответа. Из-за OCR и переносов
отсутствие совпадения не доказывает отсутствия мысли или термина.
Вывод может содержать непроверенные подстрочные примечания рядом с основным текстом.

## Совместимость с текущим проектом

Сверены data/schemas/passage.schema.json и data/curated/works.csv в main.
Существующие work IDs сохранены как ссылки только для «Об учёном незнании»
и «Непостижимого». Другие local_work_id относятся лишь к staging-каталогу.
Новые source IDs и passage IDs приложения не создавались.

Текущая passage-схема поддерживает ru, en, de, la. Для будущих grc и fr
потребуется согласованное изменение схем, моделей, фильтров и тестов,
а не произвольная запись новых кодов в CSV. Здесь язык только ru.

Записи извлечения нельзя напрямую записать как primary_quote: такая запись
в текущей схеме требует is_verbatim=true, а точность этих OCR-текстов не
установлена. Статусы not_checked и rights_to_verify не повышены автоматически.

Импортёр full-text в runtime, привязка к главам/параграфам, разделение
подстрочных комментариев и поиск через браузер ещё не реализованы.
Seed, Neo4j, embeddings, Gemini и генерация не запускались.

## Публикация

В публичный Git допускается рассматривать только проектный архив после
проверки diff. Содержимое локального архива этим документом не разрешается
к публичному распространению или передаче внешним провайдерам.

## Следующие задачи

1. Получить остальные основные книги Франка по зафиксированному плану.
2. Подключить латинские соответствия Кузанского, установив способ получения.
3. Получить полные русские «Триады» и установить перевод/издание; греческий
   оригинал получить отдельно. Английскую антологию не считать полным переводом.
4. Разметить главы/параграфы и editorial/primary границы, затем готовить
   согласованный импорт без перезаписи существующих статусов seed.

Проверки должны оставаться адресными: не начинать заново сплошную научную
сверку всех текстов до появления конкретной смысловой необходимости.

## Локальная проверка на Windows — 2026-11-23

Фактическая папка корпуса на рабочем компьютере:

`C:\philosophy-corpus\primary-corpus-local-2026-11-22`

При запуске приведённых выше команд следует передавать этот путь
в параметр --root вместо C:\philosophy-corpus.

Проверка inspect_local_corpus.py завершилась успешно:
3 источника, 1552 PDF-листа, 24 произведения,
1371 фрагмент страниц.

Буквальный поиск по подстроке «непостиж» выполнен отдельно
для Кузанского и Франка. Получены результаты с адресами источников.

Это подтверждает локальную структурную целостность и работу
буквального поиска, но не точность OCR, научную проверку цитат,
права публикации или готовность retrieval/API приложения.
