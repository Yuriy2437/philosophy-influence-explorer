# Восстановление прежних исследований

Дата восстановления: 2026-11-20. Контрольная точка кода: 1344b23.
Статус: восстановительный черновик AI, не дословный протокол бесед.
Исследовательские категории этого пакета не являются типами узлов или рёбер программы.
Отдельного утверждения каждой карточки пользователем нет, если явно не указано иное.
Источники цитат в предоставленных конспектах заново массово не сверялись.
Ни одна запись не импортирована и не подключена к приложению.

## Границы полноты

Пакет сохраняет доступную часть прежней работы из текущей переписки, её резюме,
памяти о темах и выборочно прочитанных пользовательских документов.
Это не полный экспорт всех разговоров проекта. Недоступные рассуждения
не реконструируются как якобы состоявшиеся выводы.
Неизвестно, какие локальные заметки пользователь уже сохранил вне видимой истории.
Сверка отсутствия дублей сделана только с известными документами проекта и
предыдущим пакетом docs/research/README.md и docs/research/frank-cusanus.md.
Этот пакет их не заменяет: все файлы находятся в новом подкаталоге recovered.

## Как использовать

Сначала просмотреть карточки и исправить ошибки восстановления. Не подменять
ими исходные пользовательские документы. Не добавлять исходные PDF/DOCX
в публичный репозиторий. Не вставлять эти выводы в system prompt.
После рассмотрения можно отдельно согласовать коммит только этих заметок.
До этого не запускать seed, индексацию, генерацию и оценочные API.

## Известные пробелы

- полные транскрипты прежних обсуждений недоступны;
- точные места Гуссерля и Хайдеггера по всем намеченным произведениям не восстановлены;
- источник/посредник отдельных формул Кузанского у Франка не установлен;
- источник русского перевода «Триад» не отождествлён надёжно с конкретным изданием;
- исторический маршрут Палама — Кузанский не доказан;
- публикационные условия переводов остаются отдельным вопросом;
- не доказано тождество теозиса, экзистенции, интенциональности и живого знания.
