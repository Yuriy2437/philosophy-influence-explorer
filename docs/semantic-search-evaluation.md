# Воспроизводимая оценка семантического поиска

## Назначение

Инструмент повторяет 12 контрольных запросов из
docs/search-quality-checks.md и сопоставляет выдачу
с исторической разметкой пар «вопрос — passage».

Это регрессионный набор по известному небольшому корпусу,
а не независимый широкий benchmark.

## Файлы

- data/evaluation/semantic-search-v1.json — запросы,
  фильтры, целевые passages и исторические сводки.
- data/evaluation/semantic-search-judgments-v1.json —
  36 утверждённых оценок с обоснованиями.
- src/philosophy_influence_explorer/evaluation/dataset.py —
  загрузка и проверка согласованности данных.
- src/philosophy_influence_explorer/evaluation/report.py —
  построение отчёта без обращения к сервисам.
- scripts/evaluate_semantic_search.py — реальный запуск
  через существующий PassageRetriever.

## Автономные проверки

Не требуют подключения к Neo4j или embedding API:

```powershell
uv run --no-sync python -m pytest tests/test_evaluation_dataset.py tests/test_evaluation_report.py tests/test_evaluation_cli.py -q
```

Эти тесты входят в общий набор tests и запускаются
существующим GitHub Actions workflow.

## Реальный запуск

CLI использует текущие настройки Settings.
До запуска необходимо проверить целевую базу
и метаданные сохранённых embeddings.

Для сопоставления с историческим Gemini-протоколом нужны:

- NEO4J_ENABLED=true.
- Подключение к соответствующей Aura-базе.
- EMBEDDING_PROVIDER=gemini.
- EMBEDDING_MODEL=gemini-embedding-001.
- EMBEDDING_DIMENSIONS=768.
- Доступный GOOGLE_API_KEY.

Credentials не следует включать в команды, документацию,
отчёты или коммиты. Для другого окружения используйте
временные настройки процесса, не меняя локальную базу.

После подготовки окружения:

```powershell
$reportPath = Join-Path $env:TEMP (
    "semantic-search-{0}.json" -f (Get-Date -Format "yyyyMMdd-HHmmss")
)

uv run --no-sync python scripts/evaluate_semantic_search.py --output $reportPath
```

Запуск выполняет 12 последовательных обращений
к настроенному embedding-провайдеру и поиск в Neo4j.
Используются квоты и условия выбранного сервиса.

Инструмент не выполняет seed, переиндексацию
или запись в граф. Существующий файл отчёта
не перезаписывается.

## Интерпретация отчёта

- status=success означает успешное выполнение запроса,
  а не достаточность ответа.
- expected_passage_found относится только к случаям
  с заранее выбранным целевым passage.
- Для N1–N3 целевой passage не задан; соответствующее
  поле остаётся null.
- historical_judgment — прежняя оценка пары
  «вопрос — passage», а не новая оценка текущего текста.
- Отсутствие historical_judgment означает,
  что результат ещё не размечен, а не нерелевантен.
- Ошибка запроса не преобразуется в пустую успешную выдачу.
- Код завершения 0 означает отсутствие ошибок запросов
  и нарушений проверяемых фильтров.
- Отсутствие целевого passage само по себе
  не меняет код завершения.
- Совпадение модели и dataset ID не подтверждает
  неизменность корпуса.
- Similarity не является вероятностью истинности
  или мерой достаточности ответа.

## Границы

Прогон не проверяет графовое расширение, генерацию ответов,
полноту корпуса, историческое влияние или точность цитат
по изданиям.

Историческая разметка подготовлена при помощи AI
и утверждена автором проекта. Независимая оценка
несколькими экспертами не проводилась.

Для N1–N3 возвращены ранее размеченные фрагменты.
Это не означает появления прямого ответа
или автоматического распознавания его отсутствия.
